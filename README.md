# 굴러라, 금방울

「금방울전(금령전)」을 바탕으로 한 수업용 서사 RPG

- 만든이: 경포고등학교 한예지
- 원작: 작자 미상 「금방울전(금령전)」(조선 후기 국문 영웅 소설)
- 원문 대목: 수업 자료로 쓰인 「금방울전(금령전)」 전문 (읽기 쉽게 괄호 속 한자는 뺌)
- 작품 해설 참고: 수업용 전문 주석 자료(EBS 수능특강 지문 포함)
- 현대어 풀이·서술·게임 대사: 새로 씀
- 그림: OpenAI 이미지 생성(Codex CLI)으로 만든 AI 생성 이미지 (금방울은 게임 안에서 직접 그림)
- 배경음·효과음: 게임 안에서 웹 오디오로 합성(외부 음원 없음)
- 글꼴: 송명, 고운바탕, IBM Plex Sans KR (SIL Open Font License)
- 제작 도구: Claude(Anthropic), Codex(OpenAI)
